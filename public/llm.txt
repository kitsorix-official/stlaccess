# STLACCESS — STL Scale Converter for 3D Printed Miniatures

> Browser-based tool that calculates resize percentages for scaling STL files between tabletop gaming systems. Free, no upload, no login. All math runs in your browser. Built with Astro.

## What this site does

STLACCESS solves one problem: figuring out what percentage to type into your slicer to scale an STL file from one miniature scale to another. Every conversion uses a 175cm human baseline, measured to eye level (160cm) by default. The site hosts a calculator, a reference library of 45+ verified conversions, guides, and supporting tools for 3D printing hobbyists.

## How the calculator works

1. User selects a source scale (e.g. 28mm) and target scale (e.g. 32mm)
2. Calculator divides the target human height by the source human height to get a percentage
3. User enters that percentage in their slicer (PrusaSlicer, Cura, Chitubox, Lychee, Bambu Studio)
4. STL scales proportionally in the slicer

Formula: `(target scale height) / (source scale height) * 100 = percentage`

For ratio scales, the calculator converts ratio-to-mm using the 175cm baseline, then divides as normal.

## Methodology

- Human baseline: 175cm (standard reference height used by most miniature manufacturers)
- Eye level: 160cm (default measurement method for fantasy and sci-fi)
- Top of head: 175cm (used for historical kits, display busts, and ratio scales)
- All percentages verified with FDM test prints on a Bambu Lab A1 Mini
- Digital caliper measurements at 0.01mm precision
- FDM accuracy: over-extrusion can add 0.3%-0.5% to dimensions
- Thermal shrinkage: PLA and PETG shrink 0.2%-0.5% during cooling (not compensated, tends to cancel with over-extrusion)
- Layer height bias: 0.1-0.2mm stair-step error on curved surfaces at 0.08mm layers

## About

STLACCESS is a free, independent project by kitsorix (https://github.com/kitsorix-official). All percentages are calculated from a 175cm human baseline and verified with FDM test prints and digital calipers on a Bambu Lab A1 Mini. The site has no backend, no tracking, no accounts — everything runs in your browser. Source code on GitHub. The project started from frustration with scale creep in tabletop gaming and a failed local print service in Enschede, Netherlands.
