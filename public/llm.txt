# STLACCESS — STL Scale Converter for 3D Printed Miniatures

> Browser-based tool suite that calculates resize percentages for scaling STL files between tabletop gaming systems. Free, no upload, no login. All math runs in your browser. Built with Astro. The brand is **STLACCESS** — "STL scale" always refers to the *function* (scaling STL files), never to a product name.

## What this site does

STLACCESS solves one problem: figuring out what percentage to type into your slicer to scale an STL file from one miniature scale to another. Every conversion uses a 175cm human baseline, measured to eye level (160cm) by default. The site hosts the main **STL Scale Engine** (the calculator on the homepage), a reference library of 44 verified conversions, 26 game-system guides, 11 deep-dive guides, and supporting tools for 3D printing hobbyists.

## The core methodology

- **Human baseline:** 175cm (5'9"). **Eyes at 160cm.**
- **Gaming/display scales** (28mm, 32mm, 35mm, 40mm, 75mm, 6mm, 8mm, 10mm, 30mm, 15mm) are measured to **eye level**.
- **Ratio scales** (1:35, 1:27, 1:48, 1:56, 1:72, 1:100) are measured to the **top of the head**.
- **Formula:** `(target standard mm ÷ source standard mm) × 100 = slicer percentage`.

Canonical examples: 28mm → 32mm = **114.3%** (top-of-head variant 116.1%); 32mm → 28mm = **87.5%**;
1:35 → 1:56 = **62.5%**; 1:100 → 28mm = **160.0%**; 32mm → 75mm = **234.4%**.
The eye-to-top-of-head gap (~15cm) creates a **5–10%** difference in calculated scale.

## How the calculator works

1. User selects a source scale (e.g. 28mm) and target scale (e.g. 32mm)
2. Calculator divides the target standard mm by the source standard mm to get a percentage
3. User enters that percentage in their slicer (PrusaSlicer, Cura, Chitubox, Lychee, Bambu Studio)
4. STL scales proportionally in the slicer

Formula: `(target standard mm) / (source standard mm) * 100 = percentage`

For ratio scales, the calculator converts ratio-to-mm using the 175cm baseline (top-of-head), then divides as normal. Gaming scales use eye-level mm.

## Methodology

- Human baseline: 175cm (standard reference height used by most miniature manufacturers)
- Eye level: 160cm (default measurement method for fantasy and sci-fi)
- Top of head: 175cm (used for historical kits, display busts, and ratio scales)
- All percentages verified with FDM test prints on a Bambu Lab A1 Mini
- Digital caliper measurements at 0.01mm precision
- FDM accuracy: over-extrusion can add 0.3%-0.5% to dimensions
- Thermal shrinkage: PLA and PETG shrink 0.2%-0.5% during cooling (not compensated, tends to cancel with over-extrusion)
- Resin shrinkage: add 1-3% (typical ~1.5%) for UV curing
- Layer height bias: 0.1-0.2mm stair-step error on curved surfaces at 0.08mm layers

## Editing conventions

- **Brand:** always STLACCESS. The calculator is called the STL Scale Engine / STL scale calculator — a *function*, never a brand. Never write "stlscale" as a word that looks like a product name.
- **Meta titles:** keyword-first → problem/intent → brand. Pattern: `"<Keyword> | <intent> | STLACCESS"`.
- **Meta descriptions:** ≤155 characters, natural language, name what the user gets + the problem solved.
- **Guide frontmatter:** `tldr` is the Direct Answer shown in the orange box — one punchy sentence with the key number inline. `description` stays for SEO.
- **Numbers:** always derive from the 175cm/160cm baseline and the formula above. Any change must be verified against `scales.json` / `conversions.json` / `gameSystems.json`.
- **Voice:** first-person hobbyist ("I printed it myself"), plain English.
- **Build check:** `npm run build` must stay green.

## About

STLACCESS is a free, independent project by kitsorix (https://github.com/kitsorix-official). All percentages are calculated from a 175cm human baseline and verified with FDM test prints and digital calipers on a Bambu Lab A1 Mini. The site has no backend, no cookies, no accounts — cookie-free analytics (Umami) for anonymous pageview stats only. Everything runs in your browser. Source code on GitHub. The project started from frustration with scale creep in tabletop gaming and a failed local print service in Enschede, Netherlands.
